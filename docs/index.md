# Web-Based Employee Records, Attendance, and Payroll System

This project is a Laravel prototype for small-business employee records, attendance, and payroll workflows. It uses realistic sample data and simulated frontend actions to demonstrate the application without a production database or payroll processing.

## What the prototype includes

- Dashboard metrics, attendance charts, recent records, and payroll periods
- Employee directory, employee profiles, compensation history, and simulated forms
- Attendance overview, attendance records, adjustment requests, and QR scan simulation
- Payroll periods, employee payroll records, and printable payslip previews
- User management, business settings, and audit logs

> The web application needs PHP and Laravel to run. GitHub Pages publishes this documentation only; it does not host the Laravel application.
